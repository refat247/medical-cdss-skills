# CDSS Bridge Note Publisher (v1.2.1)

Autonomous Generator, Claim-Level Grounding Verifier, and Multi-Modal Publisher for Davidson Cognitive Bridge Notes (V2.2 Standard).

## Overview
This skill provides automated document synthesis across the four medical CDSS textbooks:
- *Davidson's Principles and Practice of Medicine (25th Edition)*
- *Harrison's Principles of Internal Medicine (22nd Edition)*
- *Fuster & Hurst's The Heart (15th Edition)*
- *Kumar and Clark's Clinical Medicine (11th Edition 2026)*

## Key Capabilities
1. **Davidson Bridge Note V2.2 Enforcement**: Generates 6-layer cognitive notes with protected Davidson spine, visual asset packets, and rapid revision checklists.
2. **Claim-Level Grounding Verification**: Verifies 100% of facts against local CDSS chunks to eliminate parametric hallucinations.
3. **Lanczos-4 Figure Super-Sampling**: Automatically upscales low-res OCR figures to 300 DPI with unsharp masking.
4. **Native Word Card Grid Engine**: Compiles Word (.docx) documents featuring native table card grids, eliminating broken ASCII art.
