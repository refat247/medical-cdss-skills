# Asset Specifications: 26 Production Assets

This reference defines the required output files, schemas, and formats generated by `medical-index-rag-compiler`.

---

## 1. Foundational Registries & Lexicons (Layer 1)
- `*_synonyms_and_acronyms.json`: Dictionary mapping uppercase acronyms to canonical expanded terms.
- `landmark_clinical_trials_registry.json`: Array of landmark clinical trials, acronyms, and cited page numbers.
- `index_concept_hierarchy.json`: Taxonomic parent-child tree parsed from index indentation.
- `*_typographical_anchors.json`: High-yield locators for Tables (`t`), Figures (`f`), Plates (`c`), and page spans.

---

## 2. Corpus Catalogs & Inverted Indices (Layer 2)
- `*_chunks_master_catalog.json`: Master database containing all micro-chunks with metadata, word counts, and verbatim body.
- `*_inverted_chunk_index.json`: Integer-offset posting lists for lexical search across the corpus.
- `*_trial_to_chunks_map.json`: Landmark clinical trials mapped to specific chunk IDs.
- `*_synonym_to_chunks_map.json`: Clinical acronyms mapped to specific chunk IDs.

---

## 3. Clinical Knowledge Graphs & Guardrails (Layer 3)
- `*_concept_subtrees.json`: 120-token prompt checklists for medical topics with 3+ indexed sub-facets.
- `*_index_directed_graph.json`: GraphRAG ontology modeling "See" and "See also" cross-references.
- `*_polysemy_disambiguation.json`: Branching hubs for clinically overloaded headwords.
- `*_drug_disease_safety_matrix.json`: Drug indications, contraindications, and dosing precautions.
- `*_early_exit_section_index.json`: Inverse section frequency map routing queries to specific sections in < 0.2 ms.

---

## 4. Next-Gen Optimizers & Constrained Decoding (Layer 4)
- `*_canonical_semantic_cache.json`: Instant 0.00 ms retrieval cache for common clinical queries.
- `*_differential_comparators.json`: High-risk look-alike differential diagnosis comparator matrix.
- `*_clinical_cooccurrence_graph.json`: Page co-occurrence graph for syndromic comorbidity exploration.
- `*_entity_grammar.gbnf`: Formal BNF grammar for constrained local LLM decoding (llama.cpp/vLLM).
- `*_entity_schema.json`: Strict JSON Schema with enum validation for hosted models (Gemini/OpenAI).
- `*_index_salience_bm25_weights.json`: Salience multipliers boosting index terms 2.0x-3.0x during BM25 search.

---

## 5. Engines, Evaluation & Portability (Layer 5)
- `build_inverted_chunk_index.py`: Standalone chunk indexer.
- `build_advanced_index_suite.py`: Standalone knowledge graph builder.
- `build_nextgen_index_assets.py`: Standalone optimizer builder.
- `cdss_qa_router.py`: Turnkey CLI query router and physician case vignette decomposer.
- `eval_index_retrieval.py`: Zero-dependency 768-triplet automated benchmark test harness.
- `BENCHMARK_SCORECARD.md`: Empirical verification report recording Hit@1, Hit@3, MRR, latency, and compression.
