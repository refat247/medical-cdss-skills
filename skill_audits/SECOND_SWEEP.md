# Second-Sweep Defect Report (deep read + static analysis)

Follows `INDEX.md` and `../GOAL_ALIGNMENT_REPORT.md`. Four independent read-only reviewers each took a slice of the repo; I ran static analysis myself (pyflakes, ruff, `--help` on every script) and re-checked the most serious claims.

**Verification legend**
- **✔** I re-ran it or read the exact code myself.
- **◐** A reviewer reproduced it with a script (saved under the session scratchpad); I did not re-run it.
- **○** Reading only (code or docs); not executed. Clinical statements marked ○ come from the reviewers' general knowledge and **need clinician confirmation**.

**Not covered:** anything needing the real corpora or routers; actual Gemini/Anthropic calls; Windows-only behaviour; a full `--stage auto` on a real chapter; `build_review_packet.py`; the last third of the Davidson `source_lines_*` modules and `mutation_guard`.

## 0. Corrections to my earlier reports
- **Davidson pipeline grade was too high.** I described its gates as strong. Several are fail-open or detect much less than their names imply (sections 1–2).
- **Guard is safe on NFKC; the pipeline is not.** The guard preserves `10⁹/L`; Stage 4B of the pipeline runs NFKC and turns it into `109/L` (1.3).
- **Bridge-publisher gate** is weaker than "citation integrity": it also fails open on exempt headings and ambiguous chunk IDs (section 3).
- **One reviewer claim downgraded:** compiler dropping the first chunk (C10) happens only if a chunk file begins directly with `---`; I could not confirm real files do. Treated as conditional.
- **A false alarm of mine:** my first probe of Stage 6 returned HARD-FAIL because I passed a mis-shaped gate (`unresolved_candidates` as a list). With the real shape it returns PASS on empty input (1.1).
