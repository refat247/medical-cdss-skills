# Manual activation — offline-study-guide v1.2.1

Use this only when native personal-Skill injection is unavailable, unreliable, or intentionally not being claimed.

## Procedure

1. Read the complete `SKILL.md` from this package.
2. Confirm `metadata.version` is `1.2.1` and `metadata.status` is `stable`.
3. Read `references/input-contract.md` before accepting Markdown, DOCX, or PDF input.
4. Read `references/reader-contract.md` before changing navigation, bookmarks, viewport behavior, or print.
5. Read `references/clinical-constraints.md` before modifying medical text or calculator behavior.
6. Execute the requested workflow without claiming native runtime activation.
7. Run the builder/checker/regression steps required by `SKILL.md`.

Report this exact status when manually loaded:

`MANUAL PROTOCOL LOADED — native runtime not claimed`

Do not infer native activation from package installation, picker visibility, file availability, prior-chat success, or correct-looking output.
