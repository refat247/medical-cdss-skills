# Coverage and Closure

A subset is not all. Search recall is not an exhaustive inventory unless the source/tool can prove it.

## Equation

`EXPECTED = COMPLETED + UNRESOLVED`

If EXPECTED is unknown, do not claim exhaustive workspace completion.

## Completed

In frozen scope; required content retrieved/read; required audit depth performed; findings/disposition recorded; required authorized repair re-fetched and verified.

## Closure states

ACTIVE / PARTIAL / CLOSED TO ACCESSIBLE SCOPE / UNRESOLVED.

## Re-audit triggers

Materially changed scope, new descendants, contradictory evidence, expired verification, implementation-state change, or explicit user request.

## Freshness-aware closure dimensions

Track separate closure dimensions where relevant:
- page/content coverage;
- semantic-integrity closure;
- evidence-freshness closure;
- execution/implementation closure.

A branch can be semantically audited while still not current-content complete.

L3 reopening rule: `prior L2 closure + current decision relevance + volatile unresolved claim = L3 REOPEN REQUIRED`.
