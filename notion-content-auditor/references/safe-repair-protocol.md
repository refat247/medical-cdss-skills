# Safe Repair Protocol

Detection does not authorize destruction.

## Sequence

FETCH → identify exact defect/evidence → freeze correction/propagation → smallest safe mutation → preserve descendants/evidence/history → CHANGE → RE-FETCH → VERIFY → record repair state.

## Prefer

Targeted search-and-replace, additive notes, schema-confirmed property updates.

## Avoid

Blind full-page replacement, deletion during initial audit, similarity-only merging, silent rewriting of historical evidence, treating tool acceptance as proof.

## Failure handling

DETECT → CONTAIN → FIND CAUSE → CORRECT → VERIFY → PRESERVE EVIDENCE.
