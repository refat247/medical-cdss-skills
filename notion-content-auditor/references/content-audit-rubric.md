# Content Audit Rubric

Audit each substantive page for: purpose, completeness, accuracy, currency, provenance, canonicality, duplication/overlap, contradiction/supersession, missing knowledge, action extraction, decision propagation, implementation truth, context/findability and maintenance state.

## Severity
- **CRITICAL:** high-stakes falsehood, security exposure, or dangerous canonical defect.
- **HIGH:** major contradiction, false implementation state, missing propagation, materially wrong current guidance.
- **MEDIUM:** incomplete content, meaningful overlap, stale noncritical claim, missing provenance.
- **LOW:** minor ambiguity/context/maintenance debt.

## Duplicate classes
Exact duplicate / Semantic duplicate / Overlapping content / Parent-general source / Superseded version / Distinct despite similar title.

## Primary disposition
Exactly one: PASS / UPDATE / MERGE CANDIDATE / SUPERSEDED / ARCHIVE CANDIDATE / RE-RESEARCH / HUMAN REVIEW / DO NOT USE.
