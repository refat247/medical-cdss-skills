# Antigravity Protocol (v1.0.0)

Installed (v1.0.0)

High-efficiency, token-optimized software development and planning protocol for Google Antigravity. Enforces targeted search, chunk-based edits (`replace_file_content`), zero chat clutter, and strict process intent modes (Investigatory, Fast Path, Planning Mode).

## 🚀 Intent Modes

- **Mode A (Investigatory)**: Information and research queries. Direct answer with clickable file links.
- **Mode B (Fast Path)**: Small targeted fixes (< 3 files). Directly executes edits and confirms.
- **Mode C (Planning Mode)**: Complex features and refactors. Authors `implementation_plan.md` artifact and awaits user feedback before execution.
