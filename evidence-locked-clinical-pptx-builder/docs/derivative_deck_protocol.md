# Derivative Deck Protocol

A derivative is a selection/recomposition of frozen clinical content, not a new research project.

Inputs: frozen Master Case Library, teaching architecture, storyboard/content spec and canonical parent products where available.

Allowed derivative axes: duration, audience, essential decisions, advanced/reference depth, local-resource focus, selected modules.

Requirements: stable case IDs, unchanged clinical fingerprints, source/terminology preservation, occurrence map update, new derivative spec, full build/render/audit/promotion cycle. Local constraints are context fields, not evidence fields.
