# Projector / Design Acceptance

Default floors: title 40–48 pt, body >=24 pt, citations/source labels >=16–18 pt. Treat these as defaults, not permission to make every slide dense.

Review viewing-distance practicality, density, whitespace, visual hierarchy, edge safety, alignment, spacing, source-label visibility, table readability, image clarity and visual rhythm.

Repair overflow by removing redundancy, moving appropriate detail to notes, splitting slides, restructuring layout and adjusting visuals before reducing typography.
