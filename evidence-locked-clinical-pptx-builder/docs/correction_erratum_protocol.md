# Correction / Erratum Protocol

1. Register original and correction as separate approved sources.
2. Create a correction register with exact scope locator.
3. Create supersession map rows only for text/nodes actually corrected.
4. Correction supersedes the original only within mapped scope.
5. Unchanged original text remains authoritative elsewhere.
6. Re-audit all dependent decision nodes, cases and slides.
7. A correction with ambiguous scope blocks final clinical release.
