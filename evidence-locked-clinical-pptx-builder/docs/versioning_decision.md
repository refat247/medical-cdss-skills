# Versioning Decision

**Predecessor:** `evidence-locked-clinical-pptx-builder v1.0.0` (proven by the existing v1 ZIP/package metadata).  
**New release:** `v2.1.0`.

A MAJOR bump is justified because v2 changes the project-state schema, introduces explicit operating modes, correction/erratum precedence, mandatory final-render certification semantics, RENDER-UNCERTIFIED, derivative fingerprints and new release gates. These are behavioral and schema-level changes rather than backward-compatible documentation additions.
