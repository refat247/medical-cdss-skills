# Failure / Hard-Stop Protocol

Do not guess through a failed evidence or final-release gate.

Hard stops include missing sources, ambiguous source/correction scope, unsupported clinical claims, incomplete extraction coverage, unsafe canonical mutation, unresolved clinical conflict, or unavailable renderer/font fidelity for final visual certification.

Report: failing gate, evidence checked, exact blocker, affected artifacts, smallest user decision/action needed, and whether prior frozen/canonical artifacts remain valid.
