# Artifact Naming Convention

Suggested pattern:

- `<PROJECT>_Decision_Node_Inventory_<SOURCE>_v0.1`
- `<PROJECT>_Decision_Node_Audit_Report_<SOURCE>_v1.0`
- `<PROJECT>_Cross_Source_Reconciliation_FINAL_v1.0`
- `<PROJECT>_Conflict_Terminology_Register_FINAL_v1.0`
- `<PROJECT>_Master_Candidate_Case_Library_v0.1`
- `<PROJECT>_Master_Case_Library_FINAL_v1.0`
- `<PROJECT>_Master_Case_Library_Audit_Report_v1.0`
- `<PROJECT>_Master_Case_Coverage_Matrix_FINAL_v1.0`
- `<PROJECT>_Audience_Prioritization_FINAL_v1.0`
- `<PROJECT>_Teaching_Architecture_FINAL_v1.0`
- `<PROJECT>_Slide_Storyboard_FINAL_v1.0`
- `<PROJECT>_Case_to_Slide_Mapping_FINAL_v1.0`
- `<PROJECT>_Slide_Content_Spec_FINAL_v1.0`
- `<PROJECT>_Slide_Source_Map_v1.0`
- `<PROJECT>_PPTX_Build_Report_v1.0`
- `<PROJECT>_Final_Audit_Report_v1.0`
- `<PROJECT>_Project_Handoff_vX.Y.md`

Use `CANONICAL` only after the promotion gate.
