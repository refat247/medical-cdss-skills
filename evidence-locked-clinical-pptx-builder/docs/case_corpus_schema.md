# Case Corpus Schema

The Master Case Library is a frozen clinical knowledge artifact independent of any one presentation.

Minimum fields: case ID, source-derived scenario, audience question, distinct decision, expected answer, source IDs, exact provenance, node IDs, reconciliation/conflict IDs, threshold/timing/dose, Class/LoE, source-specific terminology, teaching objective, evidence status, audit status, clinical fingerprint.

Case count is not a planning target. It emerges from extraction, case creation, deduplication and coverage audit.
