# Codex Lesson Integration Report v1.0

## Reconstructed lesson

The successful MI project did not end with a normal ChatGPT PPTX build/audit. The final presentation needed a later Codex-style visual/UI/UX/projector-readability/overflow review and correction stage. That is a workflow failure signal: clinical/provenance correctness and mechanical PPTX integrity are not enough for final clinical teaching release.

## Pre-vs-post comparison

A pre-Codex PPTX is not available in this chat. Therefore exact slide-by-slide PRE -> POST deltas cannot be reconstructed without invention. The recoverable evidence is the final artifact plus the project instruction stating that separate Codex visual correction was required.

## Generalized failure classes

- source/footer text can be present but too small to be projector-safe;
- slides can be geometrically in-bounds yet visually dense;
- contact sheets are useful triage but cannot certify individual slides;
- local operational-constraint callouts must be visually distinct from guideline evidence;
- ECG/image practice slides require legibility and provenance/copyright warnings;
- source-figure augmentation slides require visual/permission/source-role handling distinct from clinical-content mutation.

## Skill changes made

- independent QA made operational and fail-closed;
- independent reviewer must have no clinical-change authority;
- render QA can require a per-slide ledger;
- visual-review ledger now has domain columns matching the final-artifact review needs;
- final-artifact regression fixtures and reports added.
