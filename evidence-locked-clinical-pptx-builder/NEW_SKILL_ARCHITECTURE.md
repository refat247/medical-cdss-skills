# Architecture Overview

## Pipeline A — Evidence / Case Corpus

1. evidence/source lock
2. source-by-source exhaustive extraction
3. independent extraction audit -> repair -> re-audit -> freeze
4. cross-source reconciliation + conflict/terminology register
5. candidate case generation
6. case source-fidelity audit
7. deduplication/overlap adjudication
8. coverage audit including explanatory-only accounting
9. Master Case Library freeze
10. audience prioritization
11. teaching architecture / anchor paths
12. storyboard + case-to-slide mapping

## Pipeline B — Presentation / Artifact

1. slide-level specification
2. visual/source-figure register
3. speaker-note schema
4. PPTX build
5. clinical/provenance audit
6. automated structural/mechanical preflight
7. full render
8. 100% visual/projector/UI review ledger
9. repair
10. full rerender + preflight + 100% re-review
11. independent visual QA preferred for high-stakes final decks
12. canonical promotion decision
13. derivatives / advanced / reference products from frozen corpus
14. modular indexing
15. closure manifest/archive

The two pipelines intersect through frozen identifiers and provenance, not by rewriting clinical evidence during design work.
