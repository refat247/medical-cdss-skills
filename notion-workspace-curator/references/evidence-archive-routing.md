# Evidence Archive Routing

Workspace Curator owns the structural placement, reciprocal navigation and reachability verification of evidence archives and source-card child pages. It does not judge research-method correctness; route that work to `research-method-curator`. Semantic sufficiency, contradiction and freshness review belong to `notion-content-auditor`.

## Required routing

1. Search for an existing canonical synthesis/status page, durable research hub and prior evidence archive before creating anything.
2. Place one dated evidence archive beneath the canonical synthesis/status page or nearest durable research hub.
3. Preserve one child source card per material source or coherent discovery cluster when full source-level evidence exists.
4. Add a prominent forward link from the canonical synthesis/status page to the evidence archive.
5. Add return navigation from the archive and applicable source cards to the canonical synthesis/status page.
6. Preserve raw evidence, timestamps, provenance and existing archive history. Do not move or summarize away source material merely to simplify layout.
7. Re-fetch every changed page and verify the intended parent-child structure and links in both directions.

If the canonical parent is ambiguous, record the destination as `UNRESOLVED` instead of creating a competing hub.
