# Typography & Color Standard

This is an evidence-informed project default, not a claim of physiological or medical optimality.

## Reading Polarity

Use light/near-white reading pages with dark text for dense technical reading.

Dark styling may be used on the cover or rare divider pages.

## Typography

Preferred English/Latin body:
- Atkinson Hyperlegible Next
- ~11.5 pt Regular

Headings:
- H1 ~20 pt Bold
- H2 ~16 pt Bold/Semibold
- H3 ~13.5 pt Semibold

Numeric-heavy tables:
- Inter ~10.5–11 pt
- tabular lining numerals where helpful

Bengali:
- one consistent Bengali-capable companion typeface;
- full glyph coverage;
- visual weight/size harmonized with Latin body;
- embed and visually verify after export.

## Color Semantics

- dark body text
- teal/blue = information/navigation
- green = verified/current/pass
- amber = warning/inferred/benchmark-required/unresolved
- red = danger/reject/do-not-use
- gray = historical/superseded/provenance

Never rely on color alone.

## Measure and Tables

Aim roughly 60–75 characters per prose line where feasible.

For oversized tables:
simplify → restructure → split → landscape → reduce type only if needed.

## Release QA

Inspect English, Bengali, mixed lines, numbers, decimals, symbols, URLs, tables, bold/semibold, and links for substitution, clipping, overlap, wrapping, and glyph defects.
