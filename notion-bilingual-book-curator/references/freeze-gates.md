# Freeze Gates

Run after the final repair.

## Content

PASS only if:
- no known substantial duplicate/restart remains;
- no unsupported substantive addition is present;
- current/historical distinction is preserved;
- evidence states are preserved;
- provenance is intact.

## Bilingual

PASS only if:
- technical identity remains English;
- Bengali remains explanation/reasoning;
- no mechanical duplicate translation;
- no harmful forced transliteration.

## Production

PASS only if:
- no raw export artifact remains;
- no broken glyphs;
- no clipping/overlap;
- no severe orphan page;
- section headers are correct;
- tables remain readable.

## Navigation

PASS only if:
- TOC is complete;
- TOC links resolve correctly;
- bookmark tree resolves correctly when required;
- appendices are findable;
- source links remain usable.

## Builder verification

PASS only if the required repairs were verified in the actual exported artifact.

A builder report, source HTML, or claimed publish state is not sufficient by itself.

## Regression

When the previous artifact is available, PASS only if:
- every intended repair is present;
- previously closed blockers remain closed;
- unrelated substantive content did not change;
- navigation affected by reflow remains correct.

## Jargon

When a glossary patch is part of the release:
- supplied headword count matches;
- expected repeated field counts match when specified;
- insertion location is correct;
- existing glossary material remains intact.

## Evidence/Safety

PASS only if:
- benchmark is not represented as clinical validation;
- shortlist is not represented as production approval;
- unresolved/SOURCE PARTIAL states are visible.

## Freeze semantics

`PASS — FREEZE READY` means the publication artifact is editorially and structurally closed at the stated evidence snapshot.

It does NOT mean:
- every historical claim was re-researched;
- every SOURCE PARTIAL area was resolved;
- external benchmark results became local validation;
- technical benchmark results became clinical validation.

## Final Output

Exactly:

PASS — FREEZE READY

or

FAIL — FREEZE REPAIR REQUIRED

If FAIL, list only blocking defects and the smallest next repair.
