# Book Readability Audit

Assess the artifact as a book, not merely as a PDF export.

## Dimensions

- body legibility;
- heading hierarchy;
- line length;
- paragraph density;
- list formatting;
- information density;
- 10–15 second scanability;
- deep-reading continuity;
- bilingual usefulness;
- evidence hierarchy;
- current-vs-history hierarchy;
- navigation;
- TOC;
- PDF outline/bookmarks where inspectable;
- running headers;
- page/section boundaries;
- orphan/widow defects;
- source-link usability;
- table usability;
- device suitability.

## Useful Book Pattern

Major chapter:

**What this section covers**  
**Current project relevance**  
**Established (source-supported)**  
**Not established / still untested**

Then evidence.

## Reading Routes

For large books, add a page that gives routes such as:
- rapid orientation;
- learn the domain;
- understand current project decisions;
- forensic/audit route;
- provenance/source-tracing route.

## Common Production Defects

- a later chapter restarts an earlier report;
- a dated delta repeats the entire baseline;
- running header changes before the new section starts;
- appendix begins under previous header;
- one-line orphan page;
- TOC omits appendices or new front matter;
- PDF bookmark target differs from TOC target;
- `SOURCE PARTIAL` boilerplate overwhelms the page;
- independent items remain inline instead of vertical lists.

## Verdicts

PASS  
PASS WITH TARGETED REPAIR  
FAIL — MATERIAL REPAIR REQUIRED
