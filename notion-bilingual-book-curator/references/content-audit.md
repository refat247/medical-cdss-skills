# Content Audit Standard

## Audit Before Rewrite

Check:
- duplicate/repeated sections;
- semantic overlap;
- export artifacts;
- missing tables/attachments;
- broken headings;
- source URLs detached from claims;
- contradictions;
- old state presented as current;
- evidence labels lost;
- project decisions presented as external facts;
- external evidence presented as local benchmark;
- planned work presented as executed;
- benchmark presented as clinical validation;
- unexplained jargon.

## Duplicate Classification

Classify before deleting:

- EXACT DUPLICATE
- SEMANTIC DUPLICATE
- OVERLAPPING CONTENT
- HISTORICAL VERSION
- SUPERSEDED VERSION
- PARENT / GENERAL SOURCE
- DISTINCT DESPITE SIMILARITY

Only remove true redundancy.

## Current vs Historical

Where useful:

**Historical state:**  
**Current state:**  
**What changed:**  
**Impact:**

Do not invent change explanations.

## Evidence Preservation

Never strengthen:
INFERRED → VERIFIED  
NOT MEASURED → measured negative result  
BENCHMARK REQUIRED → recommended/approved  
external benchmark → local benchmark  
local benchmark → clinical validation

## Export Repair

Never publish raw:
`[table]`
`[child_page]`
`[truncated]`
`page has more blocks`

Use SOURCE PARTIAL instead of inventing missing material.
