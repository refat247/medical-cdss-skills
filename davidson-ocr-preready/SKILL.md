# Davidson OCR Pre-Ready Pipeline (v1.7.7)

Production-grade pre-processing and inlining utility designed to bridge raw multi-page OCR extractions (`TRUE_MD_WITH_IMAGES/`) into the canonical `markdown_inlined.md` format required by `davidson-rag-pipeline-antigravity`.

> [!IMPORTANT]
> **Output Location & Provenance Rules**:
> 1. **In-Place Location**: By default, all generated outputs (`{PREFIX}.pdf.markdown_inlined.md`, `assets/figures/`, and `{PREFIX}_*_AUDIT.md` reports) are placed **directly inside each chapter's corresponding input folder**.
> 2. **Mandatory Provenance Metadata**: Every output file generated (`*.markdown_inlined.md`, `*_AUDIT.md`, `*_PREREADY_REPORT.md`) MUST embed standardized top-level provenance metadata:
>    ```markdown
>    <!--
>    PROVENANCE METADATA:
>      skill_name: "davidson-ocr-preready"
>      skill_version: "1.7.7"
>      generated_at: "YYYY-MM-DDTHH:MM:SSZ"
>      source_path: "<PATH>"
>    -->
>    ```
>    This enables instant inspection of whether an output was generated by the current skill version or requires reprocessing.

---

## Capabilities

1. **Automated Table Inlining**: Reads `pages/page-*/tbl-*.md` and replaces `[tbl-X.md]` placeholders with full Markdown tables and standardized `### 1.X` headings.
2. **Decoupled Figure Asset Mapping**: Copies and renames `pages/page-*/img-*.jpeg` to canonical `assets/figures/ch{NN}_fig_{MM}.ext` files inside the chapter folder, replacing `![img-X.jpeg]` with standardized caption tags.
3. **OCR Running Header Stripping**: Cleans stray running headers (`Medical HIGHER STUDY`, single-digit page numbers) to prevent false-positive chunk cuts.
4. **Audit Reporting**: Automatically generates `{PREFIX}_TABLE_AUDIT.md`, `{PREFIX}_FIGURE_AUDIT.md`, and `{PREFIX}_PREREADY_REPORT.md` inside each input directory.
5. **Multi-Chapter Batch Processing**: Accepts multiple source directories in a single command.

## Quick Start CLI

### 1. Process a Single Chapter (Outputs In-Place in Input Folder):
```bash
python -m preready.runner --source-dir "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_01_Clinical decision-making.pdf"
```

### 2. Process Multiple Chapters in Batch:
```bash
python -m preready.runner --source-dir "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_01_Clinical decision-making.pdf" "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_02_Clinical therapeutics and good prescribing.pdf" "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_03_Clinical genetics.pdf" "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_04_Clinical immunology.pdf"
```

### 3. Immediate Downstream Execution:
Once the pre-ready source is generated in the corresponding input directory, invoke the RAG pipeline (saving into `rag_pipeline_output/`):
```bash
python -m pipeline.run_stage --stage auto --source "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_01_Clinical decision-making.pdf\Davidson_25_01_Clinical_decision-making.pdf.markdown_inlined.md" --out "D:\davidson_25_true\TRUE_MD_WITH_IMAGES\Davidson_25_01_Clinical decision-making.pdf\rag_pipeline_output"
```

## Directory Architecture & Handover Contract

```
 [Raw OCR Input Folder: TRUE_MD_WITH_IMAGES/Davidson_25_01_Clinical decision-making.pdf]
 ├─ markdown.md (raw OCR with [tbl-0.md], ![img-0.jpeg])
 ├─ pages/page-*/ (raw tbl-*.md and img-*.jpeg)
 │                           │
 │                           ▼ (python -m preready.runner --source-dir "<INPUT_FOLDER>")
 ├─ Davidson_25_01_Clinical_decision-making.pdf.markdown_inlined.md  <-- Canonical Inlined Source
 ├─ assets/figures/                                                  <-- Decoupled Figures Store
 │   ├── ch01_fig_01.jpeg

     ├── assets/figures/                                             <-- Synchronized Figures Store
```
