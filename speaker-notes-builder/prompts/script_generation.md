# Script generation prompt contract

Use the deck analysis, slide brief, rendered slide, approved source material, and timing plan.

For each included slide create:
- main_script
- compressed_script
- optional_expansion
- delivery_intent
- key_emphasis
- pause_or_point
- transition
- estimated_seconds
- cautions

Write speech, not slide transcription. The main script should usually follow:
`proposition -> evidence/mechanism -> implication -> bridge`.

Never delete a safety-critical qualifier just to shorten the script. The compressed version must preserve the core claim and any qualifier that changes clinical meaning.

Do not use labels such as “Transition:” inside spoken prose.
