# Third-party / prior-art notes

This package was independently implemented. No source code was copied from the repositories below.

Conceptual review during design included:

- `hugohe3/ppt-master` (MIT): deck-level narrative analysis, visible-content coverage discipline, semantic-burden-based narration, and separation of notes from narration metadata.
- `Nathanielguo/presentation-speaker-notes` (repository had no granted license at review time): architectural concepts such as safe source copy, three-layer scripts, timing, quality reports, and reopen verification were independently reimplemented; no code or text was copied.
- `arrabi/powerpoint-speaker-notes` (MIT): printable presenter-companion concept using slide imagery plus notes.
- `vaibhav-malpani/AI-Speaker-Notes-Generator`: reviewed for duration/tone UX ideas; its generation implementation was not used.

The clinical/CME policy, DOCX design system, deterministic checks, schemas, and implementation in this package are original to this package.
