# Presenter companion design system

## Rehearsal edition
Purpose: learn and refine the talk.

Each slide page uses:
- persistent header with slide number, section, and timing;
- real slide thumbnail;
- delivery intent;
- full main script in the largest readable text region;
- green emphasis box;
- optional orange clinical/regulatory caution box;
- short-on-time script;
- next-slide bridge.

## Live edition
Purpose: reduce cognitive load while speaking.

Prioritize:
1. slide thumbnail;
2. main script;
3. key emphasis;
4. compressed fallback;
5. next-slide bridge;
6. small timing marker.

Avoid dense metadata, engineering status, confidence fields, and audit terminology on the live page.

## Visual defaults
- A4 portrait
- high-contrast dark green navigation
- restrained medical/professional styling
- 10.5–11 pt body minimum where possible
- pale green emphasis fields
- orange only for genuine caution/jurisdiction warnings
- one source slide per presenter page
